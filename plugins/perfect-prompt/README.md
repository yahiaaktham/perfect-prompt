# perfect-prompt

A Claude Code mod that makes your first prompt complete before the main model sees it: a cheap-model gate, one round of grounded questions (one dialog each), context from your notes folder and project, optional web best practices, the assembled prompt in your prompt box for review, and lessons learned after each task.

The full README with install, usage, settings and the notes-folder fallback is one level up: [../../README.md](../../README.md).

```bash
claude plugin marketplace add yahiaaktham/perfect-prompt
claude plugin install perfect-prompt@perfect-prompt
```
